# Foundry 框架理论知识

## Foundry 框架概述

Foundry 是一个用 Rust 编写的快速、可移植且模块化的以太坊应用开发工具包。它为智能合约开发提供了完整的工具链，包括测试、部署、调试和交互等全流程功能。

## 主要组成部分

### 1. Forge - 智能合约测试框架

**核心功能**

- **单元测试**: 支持 Solidity 原生测试，无需 JavaScript
- **集成测试**: 支持复杂的多合约交互测试
- **模糊测试 (Fuzz Testing)**: 自动生成随机输入进行测试
- **不变量测试 (Invariant Testing)**: 验证合约状态的不变性
- **快速执行**: 基于 Rust 的高性能执行引擎

**测试示例**

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.13;

import "forge-std/Test.sol";
import "../src/Counter.sol";

contract CounterTest is Test {
    Counter public counter;

    function setUp() public {
        counter = new Counter();
        counter.setNumber(0);
    }

    function test_Increment() public {
        counter.increment();
        assertEq(counter.number(), 1);
    }

    function testFuzz_SetNumber(uint256 x) public {
        counter.setNumber(x);
        assertEq(counter.number(), x);
    }

    function invariant_NumberAlwaysPositive() public {
        assertTrue(counter.number() >= 0);
    }
}
```

**高级测试功能**

```solidity
contract AdvancedTest is Test {
    // 使用 vm.expectRevert 测试异常
    function test_RevertWhen_Unauthorized() public {
        vm.expectRevert("Unauthorized");
        contract.restrictedFunction();
    }

    // 使用 vm.prank 模拟不同用户
    function test_OnlyOwner() public {
        vm.prank(owner);
        contract.ownerOnlyFunction();
    }

    // 使用 vm.warp 操作时间
    function test_TimeDependent() public {
        vm.warp(block.timestamp + 1 days);
        contract.timeBasedFunction();
    }

    // 使用 vm.deal 设置余额
    function test_WithBalance() public {
        vm.deal(address(this), 1 ether);
        contract.payableFunction{value: 1 ether}();
    }
}
```

### 2. Cast - 命令行交互工具

**主要功能**

- **合约调用**: 与已部署合约进行交互
- **数据转换**: 各种数据格式转换工具
- **区块链查询**: 查询区块、交易、账户信息
- **ABI 编码/解码**: 处理合约接口数据

**常用命令示例**

```bash
# 调用合约只读函数
cast call 0x... "balanceOf(address)" 0x...

# 发送交易
cast send 0x... "transfer(address,uint256)" 0x... 1000000000000000000 --private-key 0x...

# 查询区块信息
cast block latest

# 查询交易信息
cast tx 0x...

# 数据转换
cast --to-hex 42
cast --from-wei 1000000000000000000

# ABI 编码
cast abi-encode "transfer(address,uint256)" 0x... 1000

# 计算函数选择器
cast sig "transfer(address,uint256)"

# 查询存储槽
cast storage 0x... 0

# 估算 Gas
cast estimate 0x... "transfer(address,uint256)" 0x... 1000
```

**高级功能**

```bash
# 模拟交易
cast call --trace 0x... "complexFunction()"

# 查询事件日志
cast logs --from-block 1000000 --to-block latest "Transfer(address,address,uint256)"

# 反编译字节码
cast disassemble 0x6080604052...

# 计算合约地址
cast compute-address --nonce 42 0x...
```

### 3. Anvil - 本地以太坊节点

**核心特性**

- **快速启动**: 即时启动本地测试网络
- **可配置性**: 支持自定义网络参数
- **状态管理**: 支持快照和回滚功能
- **分叉功能**: 可以分叉主网或测试网进行测试

**启动配置**

```bash
# 基本启动
anvil

# 自定义配置
anvil --port 8545 --accounts 20 --balance 10000

# 分叉主网
anvil --fork-url https://eth-mainnet.alchemyapi.io/v2/YOUR-API-KEY

# 指定区块高度分叉
anvil --fork-url https://eth-mainnet.alchemyapi.io/v2/YOUR-API-KEY --fork-block-number 18000000

# 启用挖矿间隔
anvil --block-time 12

# 设置 Gas 限制
anvil --gas-limit 30000000
```

**高级功能**

```bash
# 创建快照
curl -X POST -H "Content-Type: application/json" --data '{"jsonrpc":"2.0","method":"evm_snapshot","params":[],"id":1}' http://localhost:8545

# 恢复快照
curl -X POST -H "Content-Type: application/json" --data '{"jsonrpc":"2.0","method":"evm_revert","params":["0x1"],"id":1}' http://localhost:8545

# 设置下一个区块时间戳
curl -X POST -H "Content-Type: application/json" --data '{"jsonrpc":"2.0","method":"evm_setNextBlockTimestamp","params":[1625097600],"id":1}' http://localhost:8545
```

## 智能合约开发全流程中的作用

### 1. 项目初始化阶段

**创建新项目**

```bash
# 初始化新的 Foundry 项目
forge init my-project
cd my-project

# 项目结构
my-project/
├── foundry.toml          # 配置文件
├── src/                  # 合约源码
│   └── Counter.sol
├── test/                 # 测试文件
│   └── Counter.t.sol
├── script/               # 部署脚本
│   └── Counter.s.sol
└── lib/                  # 依赖库
```

**配置文件 (foundry.toml)**

```toml
[profile.default]
src = "src"
out = "out"
libs = ["lib"]
solc_version = "0.8.19"
optimizer = true
optimizer_runs = 200
via_ir = false

[profile.ci]
fuzz = { runs = 10_000 }
invariant = { runs = 1_000 }

[fmt]
bracket_spacing = true
int_types = "long"
line_length = 120
multiline_func_header = "all"
number_underscore = "thousands"
quote_style = "double"
tab_width = 4
wrap_comments = true

[rpc_endpoints]
mainnet = "https://eth-mainnet.alchemyapi.io/v2/${API_KEY}"
goerli = "https://eth-goerli.alchemyapi.io/v2/${API_KEY}"
```

### 2. 开发阶段

**依赖管理**

```bash
# 安装依赖
forge install OpenZeppelin/openzeppelin-contracts
forge install transmissions11/solmate

# 更新依赖
forge update

# 移除依赖
forge remove openzeppelin-contracts
```

**编译合约**

```bash
# 编译所有合约
forge build

# 编译特定合约
forge build --contracts src/MyContract.sol

# 查看编译输出
forge build --sizes
```

### 3. 测试阶段

**运行测试**

```bash
# 运行所有测试
forge test

# 运行特定测试
forge test --match-test test_Increment

# 运行特定合约的测试
forge test --match-contract CounterTest

# 详细输出
forge test -vvv

# 生成测试覆盖率报告
forge coverage

# 生成 Gas 报告
forge test --gas-report
```

**高级测试配置**

```bash
# 模糊测试配置
forge test --fuzz-runs 10000

# 不变量测试
forge test --invariant-runs 1000

# 分叉测试
forge test --fork-url https://eth-mainnet.alchemyapi.io/v2/YOUR-API-KEY
```

### 4. 部署阶段

**部署脚本示例**

```solidity
// script/Deploy.s.sol
pragma solidity ^0.8.13;

import "forge-std/Script.sol";
import "../src/MyContract.sol";

contract DeployScript is Script {
    function setUp() public {}

    function run() public {
        uint256 deployerPrivateKey = vm.envUint("PRIVATE_KEY");
        vm.startBroadcast(deployerPrivateKey);

        MyContract myContract = new MyContract();

        console.log("Contract deployed to:", address(myContract));

        vm.stopBroadcast();
    }
}
```

**执行部署**

```bash
# 模拟部署
forge script script/Deploy.s.sol --rpc-url goerli

# 实际部署
forge script script/Deploy.s.sol --rpc-url goerli --broadcast --verify

# 使用 Ledger 硬件钱包部署
forge script script/Deploy.s.sol --rpc-url mainnet --ledger --broadcast
```

### 5. 验证阶段

**合约验证**

```bash
# 在 Etherscan 上验证合约
forge verify-contract 0x... src/MyContract.sol:MyContract --etherscan-api-key YOUR_API_KEY

# 验证带构造函数参数的合约
forge verify-contract 0x... src/MyContract.sol:MyContract --constructor-args $(cast abi-encode "constructor(uint256)" 42) --etherscan-api-key YOUR_API_KEY
```

### 6. 调试和交互阶段

**使用 Cast 进行交互**

```bash
# 查询合约状态
cast call 0x... "totalSupply()"

# 发送交易
cast send 0x... "mint(address,uint256)" 0x... 1000 --private-key 0x...

# 监听事件
cast logs --address 0x... "Transfer(address,address,uint256)"
```

**调试工具**

```bash
# 使用 Chisel 进行快速测试
chisel

# 在测试中使用调试功能
forge test --debug test_MyFunction
```

## Foundry 的优势特性

### 1. 性能优势

- **Rust 实现**: 比基于 JavaScript 的工具快 10-50 倍
- **并行执行**: 支持并行测试执行
- **增量编译**: 只编译修改的文件

### 2. 开发体验

- **Solidity 原生**: 测试用 Solidity 编写，无需学习 JavaScript
- **丰富的 Cheatcodes**: 提供强大的测试辅助功能
- **详细的错误信息**: 清晰的错误追踪和调试信息

### 3. 集成能力

- **Git 子模块**: 原生支持 Git 依赖管理
- **CI/CD 友好**: 易于集成到持续集成流程
- **多链支持**: 支持各种 EVM 兼容链

### 4. 高级功能

- **分叉测试**: 在本地分叉主网进行测试
- **模糊测试**: 自动生成测试用例
- **不变量测试**: 验证合约的关键属性
- **Gas 优化**: 详细的 Gas 使用分析

## 总结

Foundry 作为现代化的智能合约开发工具链，通过其四个核心组件（Forge、Cast、Anvil、Chisel）为开发者提供了从开发、测试到部署的完整解决方案。其基于 Rust 的高性能实现、Solidity 原生的测试体验，以及丰富的调试和交互功能，使其成为智能合约开发的首选工具之一。

**核心优势总结**：

1. **高性能**: Rust 实现，执行速度快
2. **易用性**: Solidity 原生测试，学习成本低
3. **功能完整**: 覆盖开发全流程
4. **现代化**: 支持最新的开发实践和工具链集成

Foundry 的设计理念是让智能合约开发更加高效、安全和愉悦，为 Web3 开发者提供了强大而灵活的工具支持。
